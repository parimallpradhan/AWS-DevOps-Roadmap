# 🚀 AWS & DevOps Master Roadmap 

**From Cloud Fundamentals to Real-Time AWS DevOps Projects**

A structured, hands-on learning roadmap designed to help students and aspiring engineers build practical skills in AWS, Linux, DevOps tools, CI/CD, Docker, Kubernetes and Terraform.

---

## 📌 Learning Journey

**Cloud Fundamentals → Linux → AWS Core Services → AWS Networking & Security → DevOps Tools → CI/CD → Containers → Kubernetes → Terraform → Real-Time Projects → Interview Preparation**

## 🎯 What You Will Learn

- ☁️ AWS Cloud Computing and Core Services
- 🐧 Linux Administration and Shell Scripting
- 🔐 AWS IAM, VPC and Security
- 🌐 AWS Networking and Infrastructure
- 🐙 Git and GitHub
- 🐳 Docker and Containerization
- 🔧 Maven and Ansible
- ⚙️ Jenkins and CI/CD Automation
- ☸️ Kubernetes and Container Orchestration
- 🏗️ Terraform and Infrastructure as Code
- 🚀 Real-Time AWS DevOps Projects
- 💼 Resume and Interview Preparation

## ⏰ Daily Training Structure

Each session follows a practical, beginner-friendly learning approach.

| Activity                   | Duration       |
| -------------------------- | -------------- |
| 📖 Theory and Concepts     | 15 Minutes     |
| 💻 Practical Demonstration | 30 Minutes     |
| 🛠️ Hands-on Practice      | 10 Minutes     |
| 🔄 Revision and Questions  | 5 Minutes      |
| **Total**                  | **60 Minutes** |

Designed around approximately 1 hour of structured training daily. Additional practice time will improve results.

# 📚 1. Complete 90-Day Learning Roadmap

## 🟢 Phase 1 – Foundations (Days 1–10)

**Goal:** Understand Cloud Computing and Linux fundamentals.

| Day | Topic                                  | Practical / Assignment                      |
| --- | -------------------------------------- | ------------------------------------------- |
| 01  | Cloud Computing Introduction           | Understand cloud computing and its benefits |
| 02  | Public, Private & Hybrid Cloud         | Compare cloud deployment models             |
| 03  | IaaS, PaaS & SaaS                      | Identify real-world use cases               |
| 04  | Linux Introduction & Installation      | Install Ubuntu on VirtualBox                |
| 05  | Linux Basic Commands                   | Practice navigation and file commands       |
| 06  | Linux File System & Package Management | Install and remove packages                 |
| 07  | Linux Users, Groups & Permissions      | Create users and configure permissions      |
| 08  | Linux Process & Service Management     | Manage processes and services               |
| 09  | Shell Scripting                        | Write basic shell scripts                   |
| 10  | Linux Revision & Assessment            | Complete Linux practical assignment         |

## 🔵 Phase 2 – AWS Core Services (Days 11–25)

**Goal:** Build strong AWS fundamentals and understand essential cloud services.

| Day | Topic                                    | Practical / Assignment                  |
| --- | ---------------------------------------- | --------------------------------------- |
| 11  | AWS Introduction & Global Infrastructure | Explore AWS Management Console          |
| 12  | IAM – Users, Groups & Policies           | Create IAM users and groups             |
| 13  | IAM Roles & MFA                          | Configure roles and MFA                 |
| 14  | EC2 Introduction                         | Launch an EC2 instance                  |
| 15  | EC2 Instance Types & AMI                 | Create and use AMIs                     |
| 16  | EBS & EBS Snapshots                      | Attach volumes and create snapshots     |
| 17  | EC2 User Data & Key Pairs                | Automate server configuration           |
| 18  | S3 Fundamentals                          | Create buckets and upload files         |
| 19  | S3 Versioning & Lifecycle                | Configure bucket policies and lifecycle |
| 20  | S3 Storage Classes & Glacier             | Configure archival storage              |
| 21  | AWS CLI                                  | Connect AWS CLI and execute commands    |
| 22  | RDS                                      | Create MySQL RDS instance               |
| 23  | DynamoDB                                 | Create a NoSQL table                    |
| 24  | ElastiCache & Database Overview          | Understand caching use cases            |
| 25  | AWS Core Services Revision               | Complete EC2 + S3 + RDS assignment      |

## 🟣 Phase 3 – AWS Networking & Infrastructure (Days 26–40)

**Goal:** Build and deploy production-style AWS infrastructure.

| Day | Topic                           | Practical / Assignment                    |
| --- | ------------------------------- | ----------------------------------------- |
| 26  | VPC Fundamentals                | Understand AWS networking                 |
| 27  | Custom VPC & Subnets            | Create custom VPC                         |
| 28  | Internet Gateway & Route Tables | Connect public subnet to internet         |
| 29  | Security Groups & NACL          | Configure network security                |
| 30  | NAT Gateway                     | Configure private subnet internet access  |
| 31  | DHCP Options, DNS & VPC Peering | Configure network connectivity            |
| 32  | Elastic Load Balancer           | Understand ALB, NLB and load balancing    |
| 33  | Application Load Balancer       | Create an ALB                             |
| 34  | Target Groups & Health Checks   | Register multiple EC2 instances           |
| 35  | Auto Scaling Fundamentals       | Create Launch Template and ASG            |
| 36  | Auto Scaling Policies           | Configure scaling policies                |
| 37  | ASG with Load Balancer          | Build a scalable web application          |
| 38  | CloudWatch                      | Create metrics, dashboards and alarms     |
| 39  | CloudTrail                      | Monitor AWS account activity              |
| 40  | AWS Networking Project          | Deploy a highly available web application |

## 🟠 Phase 4 – Advanced AWS Services (Days 41–50)

**Goal:** Learn automation, security and application services.

| Day | Topic                           | Practical / Assignment                   |
| --- | ------------------------------- | ---------------------------------------- |
| 41  | CloudFormation Fundamentals     | Understand infrastructure as code        |
| 42  | CloudFormation Templates & JSON | Create an EC2 using a template           |
| 43  | AWS Lambda                      | Create your first Lambda function        |
| 44  | Lambda Triggers                 | Trigger Lambda using S3                  |
| 45  | SNS & SQS                       | Configure notifications and queues       |
| 46  | SES & Elastic Beanstalk         | Explore application deployment           |
| 47  | CloudFront & Route 53           | Configure CDN and DNS                    |
| 48  | AWS KMS & Security              | Understand encryption and key management |
| 49  | Storage Gateway, Snowball & DMS | Understand hybrid storage and migration  |
| 50  | AWS Security Revision           | Complete AWS security assignment         |

## 🟡 Phase 5 – DevOps Fundamentals & Git (Days 51–58)

**Goal:** Understand DevOps culture, lifecycle and source code management.

| Day | Topic                       | Practical / Assignment                      |
| --- | --------------------------- | ------------------------------------------- |
| 51  | Introduction to DevOps      | SDLC, DevOps lifecycle and culture          |
| 52  | DevOps Tools & Architecture | Understand the DevOps toolchain             |
| 53  | Git Fundamentals            | Install Git and configure account           |
| 54  | Git Commands                | Add, commit, push and pull                  |
| 55  | GitHub                      | Create repositories and upload code         |
| 56  | Git Branching & Merging     | Practice branching strategies               |
| 57  | GitHub Collaboration        | Pull requests and conflict resolution       |
| 58  | Git Project                 | Create and manage a complete GitHub project |

## 🔴 Phase 6 – Docker & Containerization (Days 59–66)

**Goal:** Understand containerization and deploy applications using Docker.

| Day | Topic                                  | Practical / Assignment            |
| --- | -------------------------------------- | --------------------------------- |
| 59  | Docker Introduction & Architecture     | Install Docker                    |
| 60  | Docker Images & Containers             | Pull and run containers           |
| 61  | Dockerfile                             | Build custom Docker images        |
| 62  | Docker Volumes                         | Persist application data          |
| 63  | Docker Networking                      | Configure container communication |
| 64  | Docker Compose                         | Run multi-container applications  |
| 65  | Docker Hub & Image Management          | Push images to Docker Hub         |
| 66  | Docker Swarm & Container Orchestration | Deploy a basic Swarm application  |

## 🟤 Phase 7 – Maven, Ansible & Jenkins (Days 67–76)

**Goal:** Automate application builds, configuration management and deployments.

| Day | Topic                             | Practical / Assignment                   |
| --- | --------------------------------- | ---------------------------------------- |
| 67  | Maven Fundamentals                | Install Maven and build Java application |
| 68  | Continuous Testing                | Execute automated test cases             |
| 69  | Ansible Introduction              | Install Ansible and configure inventory  |
| 70  | Ansible Ad-hoc Commands           | Manage remote Linux servers              |
| 71  | Ansible Playbooks                 | Write automation playbooks               |
| 72  | Ansible Roles                     | Create reusable Ansible roles            |
| 73  | Jenkins Introduction              | Install and configure Jenkins            |
| 74  | Jenkins Jobs & GitHub Integration | Create first Jenkins job                 |
| 75  | Jenkins Pipeline                  | Create CI/CD pipeline using Jenkinsfile  |
| 76  | End-to-End CI/CD                  | GitHub → Maven → Jenkins → Docker        |

## 🔷 Phase 8 – Kubernetes & Terraform (Days 77–85)

**Goal:** Learn container orchestration and infrastructure automation.

| Day | Topic                                  | Practical / Assignment                         |
| --- | -------------------------------------- | ---------------------------------------------- |
| 77  | Kubernetes Introduction & Architecture | Understand cluster architecture                |
| 78  | Kubernetes Installation                | Set up a Kubernetes learning cluster           |
| 79  | Kubernetes Pods & Deployments          | Deploy application using YAML                  |
| 80  | Kubernetes Services                    | Configure ClusterIP, NodePort and LoadBalancer |
| 81  | Kubernetes ConfigMaps & Secrets        | Manage application configuration               |
| 82  | Kubernetes Ingress & Scaling           | Configure Ingress and replicas                 |
| 83  | Terraform Fundamentals                 | Install Terraform and understand HCL           |
| 84  | Terraform Providers, Variables & State | Connect Terraform with AWS                     |
| 85  | Terraform AWS Infrastructure           | Create VPC, EC2 and S3 using Terraform         |

## 🏆 Phase 9 – Real-Time Project & Interview Preparation (Days 86–90)

**Goal:** Apply the learning through a real-time project and prepare for interviews.

| Day | Topic                                       | Practical / Assignment                            |
| --- | ------------------------------------------- | ------------------------------------------------- |
| 86  | Real-Time Project – Architecture            | Design complete AWS infrastructure                |
| 87  | Project – Infrastructure Deployment         | Create AWS resources using Terraform              |
| 88  | Project – CI/CD & Kubernetes                | Deploy application through Jenkins and Kubernetes |
| 89  | Resume & Interview Preparation              | Prepare resume and AWS/DevOps interview questions |
| 90  | Final Project Presentation & Mock Interview | Present project and complete final assessment     |
